# PLASMA

Website for the PLASMA (Plasma and Atomic Scale Processing for Material Applications)
research group at the University at Albany.

## Local development

The site is built with [Astro](https://astro.build/) and published as a static site suitable
for GitHub Pages.

```sh
npm install
npm run dev
```

Use `npm run check` to type-check the project and `npm run build` to type-check and create
the production site in `dist/`.

## Content

All editable content lives in `assets/config/`:

- `members/` for group members
- `papers/` for publications
- `research/` for research areas
- `news/` for news items
- `announcements/` for temporary site-wide notices

Each directory includes a `_schema.toml` file. These files are contributor templates and
field-level instructions; they are not rendered as content.

Add an entry by copying the relevant schema into a new TOML file. The file name becomes the
entry identifier. Matching media is optional and uses the same file name:

- Member portraits: `assets/media/members/<entry-name>.jpg` or `.png`
- Paper figures: `assets/media/papers/<entry-name>.jpg` or `.png`
- Paper PDFs: `assets/files/papers/<entry-name>.pdf`
- Research images: `assets/media/research/<entry-name>.jpg` or `.png` (any aspect ratio)
- News media: `assets/media/news/<entry-name>.jpg`, `.png`, `.gif`, or `.mp4`

Member portraits without an image use an initials-based neutral placeholder. Publications
without a figure intentionally retain an empty figure area. Research areas without an image
use a neutral placeholder; valid highlighted paper references link to their publication
entries. Research descriptions support Markdown formatting and links.
Research areas are sorted by their required numeric `order` field in ascending order;
entries with the same order are sorted alphabetically by title.
Prefix an image filename with `ai_` to match it to the otherwise identical TOML entry
(for example, `ai_asd.png` matches `asd.toml`). The website labels these images "Image
generated by AI". If both prefixed and unprefixed files exist, the unprefixed image is used.

Announcements are included in the static build and checked in the browser against their
configured start and end dates. This lets notices expire automatically without requiring a
new deployment.

## Deployment

Configure GitHub Pages to deploy the `dist/` directory generated by `npm run build`. The
site URL is configured as `https://valleelab.org` in `astro.config.mjs`.
